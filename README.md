# 🎬 YouTube Transcript Tool

Bu proje, verdiğiniz YouTube video linkinden otomatik olarak transcript (altyazı metni) çekmenizi sağlar.

## 🚀 Kurulum

Projeyi klonlayın:

```bash
git clone https://github.com/kullaniciadi/proje-adi.git
cd proje-adi

gerekli kutuphane
pip install youtube-transcript-api

▶️ Kullanım

Terminalde aşağıdaki komutu çalıştırmanız yeterlidir:

python main.py "https://youtube.url'si buraya gelecek sekilde"

📂 Çıktı
Transcript otomatik olarak alınır
Aynı klasörde transcript.txt dosyası oluşturulur
Video içeriği satır satır bu dosyaya kaydedilir
⚠️ Notlar
Her videoda transcript bulunmayabilir
Türkçe transcript yoksa İngilizce alınabilir
Bazı videolar erişim kısıtlı olabilir
